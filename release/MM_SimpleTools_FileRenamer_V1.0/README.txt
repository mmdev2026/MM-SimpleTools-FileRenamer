MM SimpleTools FileRenamer V1.0

Ein kleines Windows-Tool zum automatischen Umbenennen mehrerer Dateien
mit Präfix und fortlaufender Nummerierung.

Das Tool läuft lokal auf dem eigenen Windows-PC.
Es werden keine Dateien hochgeladen, keine Daten übertragen und keine Cloud-Dienste verwendet.
