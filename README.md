# MM SimpleTools FileRenamer V2.0 Free

Kostenloses Windows-Tool zum lokalen Umbenennen vieler Dateien und zum Zusammenführen von PDF-Dateien.

## Funktionen

* Dateien mit eigenem Präfix automatisch nummerieren
* Dateien schnell und übersichtlich umbenennen
* Letzte Umbenennung rückgängig machen (Undo)
* PDF-Dateien zusammenführen
* Verständliche Hinweise bei ungültigen Dateien
* Lokale Verarbeitung ohne Cloud und ohne Datenübertragung

## Datenschutz

Das Programm läuft vollständig lokal auf dem eigenen Windows-PC.

* Keine Cloud-Anbindung
* Keine Datenübertragung
* Keine Benutzerkonten erforderlich
* Keine Telemetrie

## Hinweis zu Windows SmartScreen

Da die Anwendung aktuell noch nicht digital signiert ist, kann Windows beim ersten Start eine SmartScreen-Warnung anzeigen.

Die Software kann über:

**Weitere Informationen → Trotzdem ausführen**

gestartet werden.
